# 🗂️ 目录结构设计

本项目采用 Monorepo (单体仓库) 模式，统一管理前后端代码、配置文件与文档。

## 🏗️ 根目录结构

```text
sanmu_dashboard/
├── 📂 src/                  # 源码目录
│   ├── 📂 backend/          # 后端代码 (Python + C++)
│   └── 📂 frontend/         # 前端代码 (Vue 3 + TS)
├── 📂 config/               # 全局配置文件 (YAML)
│   ├── 📂 system/           # 系统级配置
│   ├── 📂 plugins/          # 插件配置
│   └── 📜 user.yaml         # 用户自定义配置
├── 📂 data/                 # 本地数据存储 (Docker 挂载点)
├── 📂 docs/                 # 设计与开发文档
├── 📜 docker-compose.yml    # 服务编排文件
└── 📜 README.md             # 项目说明书
```

---

## 🐍 Backend (后端) 目录详情

路径: `src/backend/`
基于 FastAPI 的模块化设计，支持 C++ 扩展与插件系统。

```text
src/backend/
├── 📂 app/                  # FastAPI 核心应用
│   ├── 📜 main.py           # 程序入口 (App 实例化)
│   ├── 📂 api/              # API 路由定义
│   │   ├── 📜 deps.py       # 依赖注入 (Deps)
│   │   └── 📂 v1/           # V1 版本接口
│   ├── 📂 core/             # 核心配置
│   │   ├── 📜 config.py     # 加载 config/*.yaml
│   │   └── 📜 events.py     # 启动/关闭事件
│   ├── 📂 models/           # SQLAlchemy / ORM 模型
│   ├── 📂 schemas/          # Pydantic 数据校验模型
│   └── 📂 services/         # 纯业务逻辑层 (Service Layer)
├── 📂 cpp_core/             # C++ 高性能扩展
│   ├── 📂 src/              # .cpp 源文件
│   ├── 📂 include/          # .h 头文件
│   └── 📜 CMakeLists.txt    # 编译配置
├── 📂 plugins/              # 🔌 插件存放区 (User Plugins)
│   └── 📂 example_plugin/
│       ├── 📜 manifest.json # 插件元数据
│       └── 📜 __init__.py   # 插件入口
├── 📜 requirements.txt      # Python 依赖列表
└── 📜 Dockerfile            # 后端镜像构建文件
```

## 🖥️ Frontend (前端) 目录详情

路径: `src/frontend/`
基于 Vue 3 + Vite 的标准结构。

```text
src/frontend/
├── 📂 src/
│   ├── 📂 api/              # Axios 请求封装
│   ├── 📂 assets/           # 静态资源 (Logo, Fonts)
│   ├── 📂 components/       # 通用组件 (Naive UI 封装)
│   │   └── 📂 Charts/       # ECharts 图表组件
│   ├── 📂 views/            # 页面视图
│   │   ├── 📂 Dashboard/    # 仪表盘主页
│   │   └── 📂 Settings/     # 设置页
│   ├── 📂 hooks/            # Vue Composables
│   ├── 📂 store/            # Pinia 状态管理
│   ├── 📜 App.vue           # 根组件
│   └── 📜 main.ts           # 入口文件
├── 📜 index.html            # HTML 模板
├── 📜 package.json          # npm 依赖配置
└── 📜 vite.config.ts        # Vite 构建配置
```

---

## ⚙️ Config (配置) 目录详情

所有配置通过 Git 管理，实现 Configuration as Code。

```text
config/
├── 📂 system/
│   └── 📜 system.yaml       # 系统基础设施配置 (DB连接, 端口, Log级别)
├── 📂 plugins/
│   └── 📜 plugins.yaml      # 插件开关与参数配置
└── 📜 user.yaml             # 用户个性化配置 (非敏感信息)
```
